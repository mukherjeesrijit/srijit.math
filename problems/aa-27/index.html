The sum of two ideals

Let I1​,I2​ be ideals of a commutative ring R. Define the set I1​+I2​:={a+b∣a∈I1​,b∈I2​}. Which of the following statements is not necessarily true?

  1. (a) I1​+I2​ is an ideal of R.
  2. (b) I1​⊂I1​+I2​.
  3. (c) ∣I1​+I2​∣=∣I1​∣+∣I2​∣ if R is finite.
  4. (d) ∣I1​+I2​∣=∣I1​∣⋅∣I2​∣ if I1​∩I2​={0} and R is finite.
