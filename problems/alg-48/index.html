A cubic's solution set with two points

Let $m$ and $n$ be nonzero integers. Define \[ A_{m,n} = \left\{x\in\mathbb{R}: n^2x^3+2020x^2+mx=0\right\}. \] Then the number of pairs $(m,n)$ for which $A_{m,n}$ has exactly two points is

  1. (A) 0.
  2. (B) 10.
  3. (C) 16.
  4. (D) $\infty$.
