A function built from distances to intervals

Given two real numbers $a<b$, let \[d(x,[a,b]) = \min\{|x-y| : a\le y\le b\} \quad\text{for } -\infty<x<\infty.\] Then the function \[f(x) = \frac{d(x,[0,1])}{d(x,[0,1])+d(x,[2,3])}\] satisfies

  1. (A) $0\le f(x)<\frac12$ for every $x$
  2. (B) $0<f(x)<1$ for every $x$
  3. (C) $f(x)=0$ if $2\le x\le3$ and $f(x)=1$ if $0\le x\le1$
  4. (D) $f(x)=0$ if $0\le x\le1$ and $f(x)=1$ if $2\le x\le3$.
