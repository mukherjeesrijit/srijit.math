Comparisons on a nearly sorted array

Sort P=[1,2,3,5,4] ascending. Let N1​ be the number of comparisons made by Bubble Sort and N2​ by Insertion Sort. Which options are correct?

  1. (A) N1​=10, N2​=4
  2. (B) N1​>N2​
  3. (C) IS on P will perform only one swap
  4. (D) Both BS and IS on P will make at least one unnecessary comparison (comparing elements already in correct order)
