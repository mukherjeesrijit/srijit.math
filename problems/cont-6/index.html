When is xᵖ / (sin x)^q continuous?

Let $f(x)$ be the function \[ f(x) = \begin{cases} \dfrac{x^p}{(\sin x)^q} & \text{if } x>0 \\ 0 & \text{if } x=0. \end{cases} \] Then $f(x)$ is continuous at $x=0$ if

  1. (A) $p>q$
  2. (B) $p>0$
  3. (C) $q>0$
  4. (D) $p<q$.
