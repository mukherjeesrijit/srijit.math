Metric Spaces & Topology · Compactness · Problem 1

A circle and a square

Let $X$ and $Y$ be subsets of $\mathbb{R}^2$ defined as \[ X = \{(x, y) \in \mathbb{R}^2 : x^2 + y^2 = 1\} \quad \text{and} \quad Y = (\{-1, 1\} \times [-1, 1]) \cup ([-1, 1] \times \{-1, 1\}). \] Then $X$ and $Y$ are equipped with the metric $d$ defined by \[ d((x, y), (x', y')) = \sqrt{(x - x')^2 + (y - y')^2}. \] Which of the following statements is correct?

  1. (a) There is a continuous one-one function $f : X \to Y$ which is not surjective.
  2. (b) There is a function $f : X \to Y$ satisfying $d(f(x), f(y)) = d(x, y)$ for all $x, y \in X$.
  3. (c) There is a bijective continuous function $f : X \to Y$ such that $f^{-1}$ is also continuous.
  4. (d) There is no non-constant continuous function from $X$ to $Y$.
