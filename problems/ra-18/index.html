Orthogonal to every even power

Let $f : [-1, 1] \to \mathbb{R}$ be a continuous function such that \[ \int_{-1}^1 f(x)x^{2n}\,dx = 0 \] for all $n \ge 0$. Which of the following statements is necessarily false?

  1. (a) $\int_{-1}^1 f(x)^2\,dx = \int_{-1}^1 f(-x)^2\,dx$.
  2. (b) $\left(\sup_{x\in[-1,1]} f(x)\right) + \left(\inf_{x\in[-1,1]} f(x)\right) = 0$.
  3. (c) $f(0) \ne 0$.
  4. (d) $f(1/2)f(-1/2) \le 0$.
