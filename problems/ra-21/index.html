Translates of an increasing function

Let f:[0,∞)→R be a monotone increasing function, and define fn​:[0,∞)→R by fn​(x)=f(x+n), x∈[0,∞), for all n≥1. Suppose that for some x0​∈[0,∞), the limit limn→∞​fn​(x0​) exists. Which of the following statements is necessarily false?

  1. (a) The sequence {fn​} converges pointwise on [0,∞).
  2. (b) The sequence {fn​} converges uniformly on [0,∞).
  3. (c) The limit limx→∞​f(x) exists.
  4. (d) The function f is unbounded on [0,∞).
