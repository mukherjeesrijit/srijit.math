A discontinuous function with a continuous partner

Suppose g:[0,1]→R is a continuous function and f:[0,1]→R is a function satisfying the following conditions:

(i) f(0)>0;

(ii) f(1)<0;

(iii) the function h:[0,1]→R defined by h(x)=f(x)+g(x) is monotonically increasing.

Let A={x∈[0,1]:f(x)≥0} and let x0​=supA.

(a) Prove that f(x0​)≥0.

(b) Prove that there exists t∈[x0​,1] such that g(t)=h(x0​).

(c) Prove that f(x0​)=0.

Source: ISI MMath
