Real Analysis · Sequences · Problem 5

A recursive sequence from x₁ = −10

Let $\{x_n\}_{n\ge1}$ be a sequence given by \[ x_n = \frac23\left(x_{n-1}+\frac{2}{x_{n-1}}\right), \qquad \text{for } n\ge2, \] with $x_1=-10$. Then which of the following statement(s) is/are correct?

  1. (A) $\{x_n\}_{n\ge1}$ converges
  2. (B) $\{x_n\}_{n\ge1}$ diverges
  3. (C) $x_{2025}-x_{2024}$ is positive
  4. (D) $x_{2025}-x_{2024}$ is negative
