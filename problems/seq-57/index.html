N(ε) for (n+1)/(n+5)

Let $x_n = \dfrac{n+1}{n+5}$ for $n=1,2,3,\ldots$. For each $\epsilon>0$, define \[ N(\epsilon) = \min\{k : |x_n-1|<\epsilon \text{ for all } n\ge k\}. \] Then $N\left(\dfrac{1}{1000}\right)$ is

  1. (A) greater than 3000
  2. (B) less than 1000
  3. (C) equal to 2500
  4. (D) none of the above.
