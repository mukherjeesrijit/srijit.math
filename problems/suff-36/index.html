Statistical Estimation · Lesson 2 · Problem 2

A five-point family in θ

Let $X$ be a random variable taking values $-1, 0, 1, 2, 3$ such that \[ P_\theta(X = x) = \begin{cases} 2\theta(1-\theta) & \text{if } x = -1, \\ \theta^x (1-\theta)^{3-x} & \text{if } x = 0,1,2,3. \end{cases} \] where $\theta \in (0,1)$. Show that $E_\theta(U(X)) = 0$ for all $\theta \in (0,1)$ if and only if $U(k) = a\,U^\star(k)$ for some $a \in \mathbb{R}$, where \[ U^\star(k) = \begin{cases} 0 & \text{if } k = 0,3, \\ 1 & \text{if } k = -1, \\ -2 & \text{if } k = 1,2. \end{cases} \]
