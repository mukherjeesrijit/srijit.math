A normal mixture with a Bernoulli switch

Suppose X1​ and X2​ are two independent and identically distributed random variables with Normal(θ,1) distribution. Further, consider a Bernoulli random variable V with P[V=1]=1/4, which is independent of X1​ and X2​. Define X3​ as X3​={X1​X2​​when V=0,when V=1.​ For testing H0​:θ=0 against H1​:θ=1 consider the test: Reject H0​ if (X1​+X2​+X3​)/3>c. Find c such that the test has size 0.05.
