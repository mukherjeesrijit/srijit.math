The power of a normal test

Let $X_1,X_2,\ldots,X_n$ $(n>1)$ be a random sample from a $N(\mu,1)$ distribution, where $\mu\in\mathbb{R}$ is unknown. Let $0<\alpha<1$. To test the hypothesis $H_0:\mu=0$ against $H_1:\mu=\delta$, where $\delta>0$ is a constant, let $\beta$ denote the power of the size $\alpha$ test that rejects $H_0$ if and only if $\frac1n\sum_{i=1}^n X_i > c_\alpha$, for some constant $c_\alpha$. Then which of the following statements is/are true?

  1. (A) For a fixed value of $\delta$, $\beta$ increases as $\alpha$ increases
  2. (B) For a fixed value of $\alpha$, $\beta$ increases as $\delta$ increases
  3. (C) For a fixed value of $\delta$, $\beta$ decreases as $\alpha$ increases
  4. (D) For a fixed value of $\alpha$, $\beta$ decreases as $\delta$ increases
