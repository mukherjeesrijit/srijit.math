Algebra

1. Foundations & linear systems

  • Absolute value: $|x| = \max(x, -x)$; $|x - a|$ is the distance from $x$ to $a$. $|x| < r \iff -r < x < r$. Solve $|f| = |g|$ by $f = \pm g$, or by cases at the points where the insides change sign.
  • Sums of distances: $\sum|x - a_i|$ is least at a median of the $a_i$ (anywhere between the two middle ones for an even count).
  • Linear inequalities in two variables describe half-planes; a linear expression is extreme at a corner of the region.
  • Linear systems: $ax + by = e$, $cx + dy = f$ has a unique solution iff $ad - bc \ne 0$ (Cramer: $x = \frac{ed - bf}{ad - bc}$). Otherwise there are none or infinitely many.
  • Functional equations with $f(-x)$: put $-x$ for $x$ to get a second equation and solve the linear system (e.g. $2f(x) + 3f(-x) = 15 - 4x$).
  • Sets: $A \setminus B = A \cap B^c$; De Morgan $(A \cup B)^c = A^c \cap B^c$; $|A \cup B| = |A| + |B| - |A \cap B|$.

2. Polynomials

  • Remainder theorem: $p(x) = (x - a)q(x) + p(a)$. Factor theorem: $(x - a) \mid p(x) \iff p(a) = 0$.
  • Roots of unity as test points: $x^2 + x + 1$ divides $p$ iff $p(\omega) = 0$ for a primitive cube root $\omega$ (use $\omega^3 = 1$, $1 + \omega + \omega^2 = 0$).
  • Vieta: for $x^3 + ax^2 + bx + c$ with roots $r_i$: $\sum r_i = -a$, $\sum r_ir_j = b$, $r_1r_2r_3 = -c$. Power sums follow by Newton: $p_k = e_1p_{k-1} - e_2p_{k-2} + e_3p_{k-3}$.
  • Counting real roots: sign changes (Descartes), values at chosen points (IVT), and turning points ($p'$): between two roots there is a root of $p'$ (Rolle).
  • Rational roots: a root $\frac pq$ in lowest terms of an integer polynomial has $p \mid a_0$, $q \mid a_n$.
  • Integer polynomials: $a - b \mid p(a) - p(b)$.
  • Identities: a polynomial of degree $\le n$ vanishing at $n + 1$ points is $0$; Lagrange interpolation $\sum_i y_i\prod_{j\ne i}\frac{x - x_j}{x_i - x_j}$ is the polynomial through given points.
  • Symmetric polynomial equations ($x^4 + ax^3 + bx^2 + ax + 1$): divide by $x^2$ and put $t = x + \frac1x$.

3. Quadratics

  • $ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a}$: vertex at $x = -\frac{b}{2a}$.
  • Discriminant $D = b^2 - 4ac$: two real roots, a double root, or none as $D > 0$, $= 0$, $< 0$.
  • Roots $\alpha, \beta$: $\alpha + \beta = -\frac ba$, $\alpha\beta = \frac ca$. "One root twice the other": $\beta = 2\alpha$ gives $2b^2 = 9ac$.
  • Sign of a quadratic: with $a > 0$ it is negative exactly between the roots; $ax^2 + bx + c > 0$ for all $x$ iff $a > 0$ and $D < 0$.
  • Location of roots: both roots exceed $k$ iff $D \ge 0$, $af(k) > 0$ and $-\frac{b}{2a} > k$.
  • Equations in $|x|$ or $x^2$: substitute $t = |x|$ or $t = x^2$, solve for $t \ge 0$, then count the $x$.
  • A quadratic squeezed between bounds: $0 \le f \le (x - 1)^2$ forces $f(1) = 0$ to be a minimum, so $f = a(x - 1)^2$.

4. Exponents, radicals & logarithms

  • $a^{m}a^{n} = a^{m+n}$, $(a^m)^n = a^{mn}$, $a^{m/n} = \sqrt[n]{a^m}$.
  • Conjugates: $(a + \sqrt b)^n + (a - \sqrt b)^n$ is an integer; if $0 < a - \sqrt b < 1$, it gives the integer part of $(a + \sqrt b)^n$.
  • Telescoping geometric sums: $1 + t + \dots + t^{n-1} = \frac{t^n - 1}{t - 1}$ (e.g. with $t = 2^{1/5}$).
  • Radical equations: substitute ($u = \sqrt[4]{x}$), square carefully and check for extra roots.
  • Logarithms: $\log(ab) = \log a + \log b$, $\log_ab = \frac{\log b}{\log a}$, $a^{\log_bc} = c^{\log_ba}$.

5. Rational expressions

  • Inequalities $\frac{P}{Q} > 0$: mark the zeros of $P$ and $Q$ on the line and read off the signs; never multiply by $Q$ unless its sign is known.
  • Partial fractions: $\frac{1}{k(k+1)} = \frac1k - \frac1{k+1}$; repeated and quadratic factors take $\frac{A}{(x - a)^2}$, $\frac{Bx + C}{x^2 + px + q}$ terms.
  • Range of $\frac{ax^2 + bx + c}{dx^2 + ex + f}$: set it equal to $y$ and require a real $x$ (discriminant $\ge 0$), or substitute $u = (x - h)^2$.
  • Symmetric conditions: $\frac1a + \frac1b + \frac1c = \frac{1}{a + b + c}$ is the same as $(a + b)(b + c)(c + a) = 0$.

6. Functions, sequences & series

  • AP: $a_n = a + (n - 1)d$, $S_n = \frac n2(a_1 + a_n)$. GP: $a_n = ar^{n-1}$, $S_n = a\frac{r^n - 1}{r - 1}$, $S_\infty = \frac{a}{1 - r}$ for $|r| < 1$.
  • AGP: $\sum_{n\ge1}nx^n = \frac{x}{(1 - x)^2}$ for $|x| < 1$ (differentiate the geometric series, or multiply by $x$ and subtract).
  • Telescoping: write the term as $u_k - u_{k+1}$; the sum is $u_1 - u_{n+1}$.
  • Means: for positive $a, b$: $\text{AM} = \frac{a + b}{2} \ge \text{GM} = \sqrt{ab} \ge \text{HM} = \frac{2ab}{a + b}$, and $\text{GM}^2 = \text{AM}\cdot\text{HM}$.
  • Sequences from totals: if $S_n$ is given, $a_n = S_n - S_{n-1}$.
  • Iterated maps: $f(x) = ax + b$ has $f^{(n)}(x) = a^nx + b\frac{a^n - 1}{a - 1}$.
  • Recursive definitions: compute small cases, guess the pattern, prove by induction.

7. Inequalities

  • AM–GM: $\frac{x_1 + \dots + x_n}{n} \ge \sqrt[n]{x_1\cdots x_n}$, equality iff all equal. To maximise $xy^2z^3$ with $x + y + z$ fixed, split as $x + \frac y2 + \frac y2 + \frac z3 + \frac z3 + \frac z3$.
  • Cauchy–Schwarz: $(\sum a_ib_i)^2 \le \sum a_i^2\sum b_i^2$, equality iff proportional. Consequence: $\sum\sqrt{x_i} \le \sqrt{n\sum x_i}$ and $\sum x_i^2 \ge \frac{(\sum x_i)^2}{n}$.
  • Cyclic sums: $\frac{a_1}{a_2} + \frac{a_2}{a_3} + \dots + \frac{a_n}{a_1} \ge n$ (AM–GM, the product is $1$).
  • Triangle inequality: $|a + b| \le |a| + |b|$; for complex numbers too.
  • Rearrangement: $\sum a_ib_i$ is largest when both are sorted the same way.
  • Squares are non-negative: many inequalities are $\sum(\text{something})^2 \ge 0$, e.g. $a^2 + b^2 + c^2 \ge ab + bc + ca$.
  • Recurrences: for $u_{n+1} = u_n + \frac1{u_n}$, square: $u_{n+1}^2 = u_n^2 + 2 + \frac{1}{u_n^2}$, then bound the sum.
