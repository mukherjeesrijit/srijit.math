Linear Algebra

1. Vector spaces

A vector space over $\mathbb R$ is a set $V$ with addition and scalar multiplication satisfying:

  • addition is commutative and associative, there is a zero vector $0$, and each $v$ has an additive inverse $-v$;
  • $a(u+v)=au+av$, $(a+b)v=av+bv$, $(ab)v=a(bv)$, and $1\cdot v=v$.

Standard examples

  • $\mathbb R^n$.
  • $M_{m\times n}(\mathbb R)$, the $m\times n$ real matrices, which has dimension $mn$.
  • $P_n$, the real polynomials of degree $\le n$, which has dimension $n+1$.
  • Continuous functions on an interval (infinite-dimensional).

2. Subspaces

$W\subseteq V$ is a subspace if $0\in W$ and $au+bv\in W$ for all $u,v\in W$ and scalars $a,b$.

Standard subspaces

  • The kernel and image of a linear map.
  • The span of any set of vectors.
  • Intersections of subspaces. (A union is generally not a subspace.)
  • The sum $U+W=\{u+w\}$.
  • The orthogonal complement $W^\perp$.

Dimension formula: $\dim(U+W)=\dim U+\dim W-\dim(U\cap W)$.

Direct sum: $V=U\oplus W$ means $V=U+W$ and $U\cap W=\{0\}$. Then every $v$ is written uniquely as $u+w$, and $\dim V=\dim U+\dim W$.

Counting dimensions of matrix subspaces

  • Symmetric $n\times n$ matrices: $\frac{n(n+1)}2$.
  • Skew-symmetric $n\times n$ matrices ($A^t=-A$): $\frac{n(n-1)}2$. The diagonal must be zero and the upper triangle determines the rest.
  • Trace-zero $n\times n$ matrices: $n^2-1$. The trace is a nonzero linear functional, and the kernel of a nonzero functional has codimension $1$.
  • Block-diagonal matrices with independent blocks: the dimensions add.

3. Span, independence, basis, dimension

  • $\operatorname{span}(S)$ is the set of all finite linear combinations of vectors in $S$.
  • $v_1,\dots,v_k$ are linearly independent if $\sum c_iv_i=0$ forces all $c_i=0$.
  • A basis is a linearly independent spanning set. Every $v$ has a unique expression in a basis.
  • Steinitz exchange: in a space spanned by $m$ vectors, any independent set has at most $m$ vectors. Hence all bases have the same size, called $\dim V$.
  • In an $n$-dimensional space, any $n$ independent vectors form a basis, and any $n$ spanning vectors form a basis.
  • Every independent set extends to a basis, and every spanning set contains a basis.

4. Inner products and orthogonality

An inner product $\langle\cdot,\cdot\rangle$ on a real vector space is symmetric, linear in each slot, and positive definite ($\langle x,x\rangle>0$ for $x\ne0$). On $\mathbb R^n$ the standard one is $\langle x,y\rangle=x^ty$.

  • Norm: $\|x\|=\sqrt{\langle x,x\rangle}$, with $\|cx\|=|c|\,\|x\|$.
  • Cauchy–Schwarz: $|\langle x,y\rangle|\le\|x\|\|y\|$.
  • Triangle inequality: $\|x+y\|\le\|x\|+\|y\|$.
  • Orthogonal: $x\perp y$ when $\langle x,y\rangle=0$. Orthogonal nonzero vectors are independent.
  • Orthogonal complement: $W^\perp=\{x:\langle x,w\rangle=0\ \forall w\in W\}$. In $\mathbb R^n$:
    • $\dim W+\dim W^\perp=n$;
    • $\mathbb R^n=W\oplus W^\perp$;
    • $(W^\perp)^\perp=W$.
  • Gram–Schmidt turns any basis into an orthonormal basis.
  • For a matrix $A$: $(\operatorname{Col}A)^\perp=\ker A^t$ and $(\operatorname{Row}A)^\perp=\ker A$.

5. Linear maps

$T:V\to W$ is linear if $T(au+bv)=aT(u)+bT(v)$.

  • $\ker T=\{v:Tv=0\}$ is a subspace of $V$. $\operatorname{Im}T=\{Tv\}$ is a subspace of $W$.
  • $T$ is one-one $\iff\ker T=\{0\}$.
  • $T$ is onto $\iff\operatorname{Im}T=W$.
  • A linear map is determined by its values on a basis, and these values can be chosen freely.
  • Compositions and sums of linear maps are linear.
  • $T$ is an isomorphism (invertible) $\iff$ it is one-one and onto. Spaces of equal finite dimension are isomorphic. For $\dim V=\dim W<\infty$, one-one $\iff$ onto.

Maps and norms: if $\|Tx\|=c\|x\|$ for all unit $x$ with $c>0$, then by homogeneity $\|Tx\|=c\|x\|$ for all $x$. Hence $\ker T=0$ and $T$ is injective. Such a map is $c$ times an isometry, and it requires $n\le m$. It is not necessarily onto, and it is unbounded in the sense that $\|Tx\|$ grows with $\|x\|$.

6. Matrices and change of basis

  • For bases $\mathcal B$ of $V$ and $\mathcal C$ of $W$, the matrix $[T]_{\mathcal B}^{\mathcal C}$ has columns $[Tb_j]_{\mathcal C}$. Then $[Tv]_{\mathcal C}=[T]_{\mathcal B}^{\mathcal C}[v]_{\mathcal B}$.
  • Matrix multiplication corresponds to composition of maps.
  • Change of basis for an operator: if $P$ is the matrix whose columns are the new basis vectors written in the old basis, then $[T]_{\text{new}}=P^{-1}[T]_{\text{old}}P$.

Invertibility. For an $n\times n$ matrix, the following are equivalent:

  • $A$ is invertible.
  • $\det A\ne0$.
  • $\operatorname{Rank}A=n$.
  • $\ker A=\{0\}$.
  • The columns (or rows) are independent.
  • $0$ is not an eigenvalue.
  • $Ax=b$ has a unique solution for every $b$.

7. Rank, kernel, and rank–nullity

Rank. $\operatorname{Rank}A=\dim\operatorname{Col}A$, the dimension of the column space. It equals the dimension of the row space, so $\operatorname{Rank}A=\operatorname{Rank}A^t$. It also equals the number of pivots after row reduction.

Rank–nullity theorem. For $T:V\to W$ with $V$ finite-dimensional,

$$\dim V=\dim\ker T+\dim\operatorname{Im}T.$$

Idea of proof: extend a basis of $\ker T$ to a basis of $V$. The images of the added vectors form a basis of $\operatorname{Im}T$.

Rank inequalities

  • $\operatorname{Rank}A\le\min(m,n)$ for an $m\times n$ matrix.
  • $\operatorname{Rank}(AB)\le\min(\operatorname{Rank}A,\operatorname{Rank}B)$.
  • $\operatorname{Rank}(A+B)\le\operatorname{Rank}A+\operatorname{Rank}B$.
  • $\operatorname{Rank}A\le$ the number of nonzero rows, and $\le$ the number of nonzero columns.
  • Multiplying by invertible matrices on either side doesn't change rank.

Rank-one matrices. $\operatorname{Rank}A=1\iff A=uv^t$ with $u,v\ne0$. Then the nonzero entries are $a_{ij}=u_iv_j$, and the count of nonzero entries is (number of nonzero $u_i$) $\times$ (number of nonzero $v_j$). In a $4\times4$ matrix, a rank-one matrix therefore has $pq$ nonzero entries with $p,q\in\{1,2,3,4\}$, and $5$ is not such a product.

Left kernel. $\{y:y^tA=0\}$ has dimension $m-\operatorname{Rank}A$. A nonzero $B$ with $BA=0$ exists exactly when $\operatorname{Rank}A<m$, because each row of $B$ must lie in the left kernel. Any matrix with a zero row has rank less than its number of rows.

8. Eigenvalues, eigenvectors, characteristic polynomial

  • $\lambda$ is an eigenvalue of $A$ if $Av=\lambda v$ for some $v\ne0$ (an eigenvector). Equivalently, $\det(A-\lambda I)=0$.
  • The eigenspace $E_\lambda=\ker(A-\lambda I)$ has dimension called the geometric multiplicity.
  • The characteristic polynomial $p_A(x)=\det(xI-A)$ has degree $n$. Its coefficients involve the trace and determinant:
    • the coefficient of $x^{n-1}$ is $-\operatorname{tr}A$;
    • the constant term is $(-1)^n\det A$.
  • The algebraic multiplicity of $\lambda$ is its multiplicity as a root of $p_A$.
  • Always: $1\le\text{geometric}\le\text{algebraic}$.
  • Sums and products: the eigenvalues (with multiplicity) add up to $\operatorname{tr}A$ and multiply to $\det A$.
  • Eigenvectors for distinct eigenvalues are linearly independent.
  • If $\lambda$ is an eigenvalue of $A$, then $f(\lambda)$ is an eigenvalue of $f(A)$ for any polynomial $f$. For invertible $A$, $\lambda^{-1}$ is an eigenvalue of $A^{-1}$.
  • A triangular matrix has its diagonal entries as eigenvalues.

Cayley–Hamilton theorem. $p_A(A)=0$.

Minimal polynomial. $m_A$ is the monic polynomial of least degree with $m_A(A)=0$. It divides every polynomial that annihilates $A$ (in particular $p_A$), and it has the same roots as $p_A$.

Inverse via Cayley–Hamilton. If $p_A(x)=x^3+c_2x^2+c_1x+c_0$ with $c_0\ne0$, then

$$A^3+c_2A^2+c_1A=-c_0I\ \Rightarrow\ A^{-1}=-\tfrac1{c_0}\left(A^2+c_2A+c_1I\right).$$

For eigenvalues $1,2,3$: $p_A(x)=x^3-6x^2+11x-6$, so $A^{-1}=\tfrac16(A^2-6A+11I)$.

9. Similarity

$A\sim B$ if $B=P^{-1}AP$ for some invertible $P$, meaning the two matrices represent the same operator in different bases. Similarity is an equivalence relation.

Preserved by similarity (invariants):

  • rank and nullity;
  • determinant and trace;
  • invertibility;
  • characteristic polynomial, minimal polynomial, eigenvalues with multiplicities;
  • $\dim\ker(A-\lambda I)^j$ for every $\lambda$ and $j$.

Not preserved as sets: the kernel, image and eigenvectors themselves. They are moved by $P$: $\ker B=P^{-1}(\ker A)$. Only their dimensions agree.

Two matrices with the same characteristic polynomial need not be similar (for example $0$ and $\begin{pmatrix}0&1\\0&0\end{pmatrix}$).

10. Diagonalizability

$A$ is diagonalizable if $A=PDP^{-1}$ with $D$ diagonal.

Equivalent conditions

  • $\mathbb R^n$ has a basis of eigenvectors of $A$.
  • The geometric multiplicity equals the algebraic multiplicity for every eigenvalue, and $p_A$ splits into linear factors over the field.
  • The minimal polynomial is a product of distinct linear factors.

Sufficient conditions: $n$ distinct eigenvalues, or $A$ real symmetric (spectral theorem).

Spectral theorem. A real symmetric matrix has real eigenvalues, eigenvectors for different eigenvalues are orthogonal, and $A=Q\Lambda Q^t$ with $Q$ orthogonal and $\Lambda$ diagonal.

Failure of diagonalizability happens when some geometric multiplicity is strictly smaller than the algebraic one, which leads to Jordan form.

11. Nilpotent operators and Jordan form

Nilpotent. $T^k=0$ for some $k$. Then:

  • the only eigenvalue is $0$ (if $Tv=\lambda v$, then $0=T^kv=\lambda^kv$);
  • $p_T(x)=x^n$ and the minimal polynomial is $x^k$ for the least such $k$;
  • $T^n=0$ always, where $n=\dim V$.

Nilpotent and diagonalizable implies zero. If $T$ were diagonalizable, it would be similar to a diagonal matrix with only zeros, so $T=0$. Hence a nonzero nilpotent operator is never diagonalizable.

Case $\dim V=2$, $T^2=0$, $T\ne0$. Here $\operatorname{Im}T=\ker T$ is a line. For $v\notin\ker T$, the pair $\{v,Tv\}$ is a basis, and $T\sim\begin{pmatrix}0&0\\1&0\end{pmatrix}$. This is the only nonzero nilpotent type in $\mathbb R^2$.

Jordan block. $J_k(\lambda)$ is the $k\times k$ matrix with $\lambda$ on the diagonal and $1$ on the superdiagonal (or subdiagonal).

Jordan canonical form. If $p_A$ splits over the field, $A$ is similar to a block-diagonal matrix of Jordan blocks, unique up to reordering the blocks. For $\lambda$:

  • the number of blocks with eigenvalue $\lambda$ equals $\dim\ker(A-\lambda I)$;
  • the total size of those blocks equals the algebraic multiplicity;
  • the largest block size equals the multiplicity of $\lambda$ as a root of $m_A$;
  • the numbers $\dim\ker(A-\lambda I)^j$ determine all block sizes.

Similarity criterion. Two matrices with split characteristic polynomials are similar $\iff$ they have the same Jordan form. In particular, similar operators have equal $\dim\ker T^j$ for every $j$.

Example: differentiation on $P_5$. The operator $S=\frac d{dx}$ on polynomials of degree $\le5$ (dimension $6$) sends $x^5\to x^4\to\cdots\to x\to1\to0$.

  • It is one Jordan block $J_6(0)$.
  • $\dim\ker S=1$ and $\operatorname{Rank}S=5$.
  • $T=S^2$ has $\dim\ker T=2$ (it kills $1$ and $x$), so $T$ splits into two Jordan blocks of size $3$ and is not similar to $S$.
  • $S\circ T=T\circ S=S^3$, since powers of one operator commute. It is nilpotent, so $0$ is its only eigenvalue.
