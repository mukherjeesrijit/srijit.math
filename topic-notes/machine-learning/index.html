Machine Learning

1. Regression

  • Least squares: minimise $\sum(y_i - w^Tx_i)^2$; the solution solves $X^TXw = X^Ty$. Through the origin in one variable, $w = \frac{\sum x_iy_i}{\sum x_i^2}$.
  • Ridge regression adds $\lambda\|w\|_2^2$: $w = (X^TX + \lambda I)^{-1}X^Ty$; it shrinks weights, raising bias and lowering variance. Lasso adds $\lambda\|w\|_1$ and sets some weights to $0$.
  • Losses: squared error, absolute error (MAE), and the total regularised loss $=$ data loss $+$ penalty.
  • Gradient descent: $w \leftarrow w - \eta\nabla L(w)$; stochastic gradient descent uses one example (or a mini-batch) per step.
  • Logistic regression: $P(y = 1 \mid x) = \sigma(w^Tx + b)$ with $\sigma(z) = \frac{1}{1 + e^{-z}}$ and $\sigma' = \sigma(1 - \sigma)$; trained by maximising the log-likelihood.

2. Classification

  • Generative vs discriminative: naive Bayes models $P(x \mid y)P(y)$; logistic regression models $P(y \mid x)$.
  • Naive Bayes: assumes features independent given the class; with $K$ binary features and two classes it has $2K + 1$ parameters. Predict the class with the largest $P(y)\prod P(x_j \mid y)$; the error at $x$ is the smaller posterior.
  • $k$-nearest neighbours: majority label among the $k$ closest points; odd $k$ avoids ties.
  • Linear classifiers: $\mathrm{sign}(w^Tx + b)$. The perceptron updates $w \leftarrow w + y_nx_n$, $b \leftarrow b + y_n$ on a mistake, raising $y_nf(x_n)$ by $\|x_n\|^2 + 1$. The nearest-mean classifier is linear.
  • Hard-margin SVM: maximise the margin $\frac{2}{\|w\|}$ subject to $y_i(w^Tx_i + b) \ge 1$; the support vectors lie on $w^Tx + b = \pm1$. Data must be linearly separable (XOR-like data is not).
  • Fisher LDA: maximise $\frac{u^TS_Bu}{u^TS_Wu}$; the optimum satisfies $S_W^{-1}S_Bu = \lambda u$.
  • Decision trees: split on the attribute with the largest information gain $H(Y) - \sum\frac{|S_v|}{|S|}H(Y \mid v)$, with entropy $H = -\sum p\log_2p$.

3. Clustering & dimensionality reduction

  • $k$-means: alternate assigning points to the nearest centre and moving each centre to its cluster's mean; each cluster is convex (a Voronoi cell).
  • K-medoids: centres must be data points; more robust to outliers.
  • Hierarchical clustering: repeatedly merge the two closest clusters. Single linkage uses the closest pair, complete linkage the farthest, average linkage the mean distance; the result is a dendrogram.
  • Distances: Euclidean, Manhattan $\sum|x_i - y_i|$, cosine.
  • PCA: the principal components are orthogonal eigenvectors of the covariance matrix; the variance along the $i$-th is $\lambda_i$, and keeping the top $k$ keeps $\frac{\lambda_1 + \dots + \lambda_k}{\sum\lambda_i}$ of the variance.

4. Neural networks

  • Neuron: $a = g(w^Tx + b)$ with activation $g$: ReLU $\max(0, z)$ (continuous, not differentiable at $0$), sigmoid, tanh.
  • Parameters: a fully connected layer from $m$ to $n$ units has $mn$ weights (plus $n$ biases).
  • ReLU networks with positive inputs and weights act linearly; the end-to-end weight is the sum over paths of the products of weights.
  • Backpropagation: the chain rule layer by layer; a ReLU unit with negative input passes gradient $0$.
  • Training: loss (squared error, cross-entropy), gradient descent, regularisation (weight decay, dropout), early stopping.

5. Bias, variance & evaluation

  • Bias–variance: expected test error $=$ bias$^2$ $+$ variance $+$ noise. Simple models underfit (high bias); complex models overfit (high variance).
  • Validation: hold-out sets, $k$-fold cross-validation, leave-one-out ($n$ splits for $n$ training points). Never tune on the test set.
  • Confusion matrix: accuracy $\frac{TP + TN}{N}$, precision $\frac{TP}{TP + FP}$, recall $\frac{TP}{TP + FN}$, $F_1 = \frac{2PR}{P + R}$.
  • Preprocessing: z-score $\frac{x - \mu}{\sigma}$; min–max scaling $\frac{x - \min}{\max - \min}$.

6. Search, logic & reasoning (AI)

  • Uninformed search: BFS (complete, optimal for unit costs), DFS, depth-limited, iterative deepening, uniform cost.
  • A*: expand the node with the smallest $f = g + h$. $h$ is admissible if $0 \le h \le h^*$ (then A* is optimal); $\max(h_1, h_2)$ and $|h_1 - h_2|$ of admissible heuristics are admissible.
  • Minimax and $\alpha$–$\beta$ pruning: $\alpha$ is the best value MAX can guarantee so far, $\beta$ the best for MIN; prune when $\alpha \ge \beta$.
  • Propositional logic: $p \Rightarrow q \equiv \neg p \vee q$; contrapositive $\neg q \Rightarrow \neg p$; $X$ entails $Y$ iff $X \wedge \neg Y$ is unsatisfiable.
  • First-order logic: "all $P$ are $Q$" is $\forall x\,P(x) \Rightarrow Q(x)$; "some $P$ is $Q$" is $\exists x\,P(x) \wedge Q(x)$.
  • Bayesian networks: $P(x_1, \dots, x_n) = \prod P(x_i \mid \text{parents})$. Given a node, its children are independent of its parents' other descendants; two parents become dependent given their common child. Variable elimination is exact; Gibbs, rejection and likelihood-weighted sampling are approximate.
